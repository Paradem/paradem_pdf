# Troubleshooting

## Node, Puppeteer, or Chrome cannot be found

The gem does not install Node packages or a browser. Ensure Node is available to
Grover's configured runtime and Puppeteer resolves from the rendering process's
working directory. Supply `options: {executable_path: "/path/to/chrome"}` when
using an explicit executable.

The launcher resolves `puppeteer`, then `puppeteer-core`, using the same working
directory lookup as Grover's worker. A compatible Puppeteer release must provide
the browser context APIs used by [worker_context.cjs](../lib/paradem_pdf/worker_context.cjs).
See [browser-check.md](browser-check.md) for the fixture environment, not a promise
that every Puppeteer/Chrome combination works.

## Images or fonts fail

Check that asset URLs are accessible to the browser, use the intended origin,
and do not depend on authentication the browser lacks. Request failures must
raise; do not disable that control to hide broken assets.

`PDF image failed`, `PDF font failed`, and `PDF readiness timeout` identify
resource readiness failures. Each decoration is a separate HTML document and
needs its own CSS and fonts. Increasing `readiness_timeout` only changes the
resource deadline, not launch, navigation, or conversion deadlines.

For application-driven asynchronous content, supply an awaited Grover
`execute_script` that establishes readiness, or choose an explicit native
waiting policy. A custom script replaces the generic image/font hook, so it
must handle any resource checks the application needs.

Sources: [grover_renderer.rb](../lib/paradem_pdf/grover_renderer.rb),
[readiness.js](../lib/paradem_pdf/readiness.js).

## Headers or footers overlap, or geometry is rejected

Reserve enough top and bottom space in `body_margins`. Position decorations in
their own HTML and select suitable `header_margins` and `footer_margins`.
The gem does not measure decoration height or resize margins automatically.

Use matching page format and landscape settings. Check HTML metadata for
unexpected geometry or margin overrides. Decorations must produce exactly one
page with matching visible geometry, rotation, and user unit.

See the examples in [README.md](../README.md) and validation in
[document.rb](../lib/paradem_pdf/document.rb).

## Cached output is stale

Completed hits do not call headers or footers. Declare changes to callback data,
templates, helper behavior, and translation inputs through `freshness`.
Declare image, font, CSS, and other asset changes through `assets_version`.
Compute these values from the same snapshot the callbacks render.

The gem cannot detect undeclared callback changes. Disable caching if the
dependencies cannot be declared reliably. Corrupt bytes are different from
stale valid bytes: corrupt entries regenerate automatically.

See [optimizations.md](optimizations.md) and
[document_test.rb](../test/document_test.rb).

## Cache setup or writes fail

When supplying a store, also supply a nonblank namespace, freshness, asset
version, and finite positive expiry in seconds. Use String keys in JSON-compatible
dependency Hashes, not Symbols.

Store exceptions propagate. False or nil writes return generated bytes by
default; `require_cache_write: true` raises `CacheWriteFailed` instead. Strict
mode does not make a series of decoration writes transactional.

With `ParademPdf::Rails.document`, omitting `cache` selects `Rails.cache`.
Pass `cache: nil` to disable it explicitly. See [api-reference.md](api-reference.md).

## Browser launch or cleanup fails

Do not fix sandbox errors with `--no-sandbox` or related security-bypass flags.
Use an environment with normal Chrome security support. Managed launches reject
those flags and `GROVER_NO_SANDBOX=true`.

Do not reuse a browser after its batch block exits. If cleanup raises, inspect
the exception's cause for the active render error as well. Forced cleanup is
reported as failure, not a successful render. Do not signal unrelated browser
processes to resolve an owned-browser error.

See [browser.rb](../lib/paradem_pdf/browser.rb) and
[browser_lifecycle_test.rb](../test/browser_lifecycle_test.rb).
